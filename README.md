This GitHub repo contains the code and dependencies for replication of our 2026/27 TJHSST Computer Systems Lab senior research project: a dual approach to quantifying household economic uncertainty. 

Contained in "requirements.txt" are all the packages necessary. Install for replication with the proper terminal command. 

IMPORTANT: sentiments.py relies on a connection to HuggingFace for the NLI model. Proper use requires a HuggingFace API Token, which can be set on the HuggingFace website. Code may not work without one!
